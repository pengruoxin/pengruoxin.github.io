Vision Model Reassembly · Featured Research

HeteroWeave

A framework for composing a new vision model from reusable blocks drawn from several pretrained models.

Instead of forcing every position to keep exactly one source block, HeteroWeave allows a variable number of compatible blocks to work together. It uses a low-cost candidate score and Pareto-guided search to find different accuracy–efficiency trade-offs without fully training every possible composition.
